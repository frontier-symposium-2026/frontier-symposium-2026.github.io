# 2026 Frontier Symposium

Website for the **2026 Frontier Symposium in Computational and Experimental Biophysics and Bioscience**, held November 6-8, 2026, at the RIKEN IIB Auditorium in Kobe, Japan.

The website includes the invited and planned speaker roster, organizing committee, scientific focus, host and planned co-hosts, venue, accommodation, travel-support policy, target audience, expected attendance, participation fee, registration method, and committee contacts. Items not yet finalized, including the detailed schedule and registration period, are identified as such.
