# 2026 Frontier Symposium

Website for the **2026 Frontier Symposium in Computational and Experimental Biophysics and Bioscience**, held November 6-8, 2026, at the RIKEN IIB Auditorium in Kobe, Japan.

The website includes the invited-speaker roster, organizing committee, scientific focus, venue, accommodation, travel-support policy, and committee contacts. Items not yet finalized, including the detailed schedule and general registration process, are identified as such.
